# Atividade 01 — Site RDR2 (Django)

Exercício de faculdade: site multi-página com tema Red Dead Redemption 2, construído em Django para praticar views, templates e roteamento de URLs.

## Conteúdo

- `rdr2_site/` — configuração do projeto Django
- `rdr2_app/` — app com as páginas (`sobre`, `perfil`, `contato`)

## Stack

- Python, Django

## Rodando localmente

\`\`\`bash
python manage.py migrate
python manage.py runserver
\`\`\`

Trabalho de faculdade — Desenvolvimento Web.
